# Privacy Policy - mob-shorts

mob-shorts is a personal automation tool run by the owner of this repository. It makes Minecraft
mob-battle videos and uploads them to the owner's own YouTube channel.

- The only Google permission it uses is `youtube.upload`, to upload videos to the owner's channel.
- It is used only by the owner. It does not collect, store, sell or share anyone else's data.
- The upload key is stored as an encrypted GitHub Actions secret and is used only to upload videos.
- It does not read, change or delete anything else in the YouTube or Google account.
- Access can be removed at any time at https://myaccount.google.com/permissions

Contact: open an issue in this repository.
